# Library System - Admin Panel

Panel administrativo para gestión de negocios con bot de ventas, productos, pedidos y métricas.

## 🚀 Quick Start

```bash
npm install
npm run dev        # Desarrollo local
npm run build      # Build para producción
npm run preview    # Preview del build
npm run typecheck  # Validar TypeScript
```

## 🏗️ Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- React Router

## 📦 Deploy

Deploy automático a Vercel en push a `main` desde `personal-bots-tuc/library-admin`.
